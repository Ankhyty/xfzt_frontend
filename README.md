# 新番杂谈网站
## 项目目标
- 实现一个支持多人查看、作者可编辑的新番内容画廊前端
  
## 用户角色
- 游客：查看画廊、浏览内容
- 作者：创建卡片（上传文字&图片）、编辑自己创建的卡片
- 管理员：新建季度、设置截止时间（前端：时间戳，后端：OK）、导出季度全量内容（前端：request，后端：文件）、编辑任意卡片、回滚版本（版本和卡片绑定，只有作者和管理员可以回滚该卡片的版本）
  
## 功能需求
- 用户登录
- 查看全部卡片
- 按类型（季度 ~~、作者、番剧名、评分~~ ）筛选卡片
- 查看单张卡片详情（客户端）
- 创建/编辑卡片
- 直传OBS
- 回滚用户操作(?)
- 搜索功能(?)
